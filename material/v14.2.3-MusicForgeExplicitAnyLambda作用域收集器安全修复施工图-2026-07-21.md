# v14.2.3 MusicForge Explicit Any Lambda 作用域收集器安全修复施工图

日期：2026-07-21

推荐基线：v14.1.2，直到本版完成最终发布验收

## 问题

schema 5 直接遍历 lambda body，导致 lambda 内海象赋值被错误写入外层
collector scope。攻击者可以用 `(Alias := int)` 隐藏 lambda 外部后续的
真实 `typing.Any` 注解，而 Python runtime 和 mypy 都不会改变外层 Alias。

## 实施范围

- collector 升级到 schema 6。
- lambda body 不参与注解收集，也不能修改外围 binding。
- 覆盖 lambda parameter、walrus、nested lambda 和 100 个外层 Any。
- 攻击语料进入独立 `v1423.explicit_any_lambda_scope_smoke`。
- schema 5 的条件导入、fail-closed 分支和 ordinary shadowing 必须保留。
- 不提高 total、layer、affected-file、per-file 或 recovery ceiling。
