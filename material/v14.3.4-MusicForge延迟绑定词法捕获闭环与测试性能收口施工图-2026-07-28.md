# v14.3.4 MusicForge Late-Bound Lexical Capture Closure

## Objective

Close the schema 15 gap where a function or lambda references a free name
before that name receives its first runtime binding. Keep every quality and
performance ceiling unchanged and restore a truthful local full-test result.

## Scope

- Upgrade the Explicit Any collector from schema 15 to schema 16.
- Replace definition-time-only closure identity tracking with stable lexical
  capture cells keyed by scope and name.
- Cover named functions, lambdas, factories, and nested functions.
- Preserve complete argument binding, generic call effects, alias returns, and
  returned-callable capture substitution.
- Add `v1434.late_bound_lexical_capture_smoke` to all v14 release profiles.
- Keep the `pytest.full` hard duration budget at 3,600 seconds.

## Non-Goals

- Do not add product behavior.
- Do not raise Any, file, layer, complexity, recovery, coverage, or performance
  ceilings.
- Do not weaken Ruff, mypy, pytest, release-check, reviewer package, or CI
  evidence requirements.

## Implementation

1. Assign stable IDs to module and function lexical scopes.
2. Record bound-name ownership in each scope without treating class bodies as
   closure scopes.
3. Create a cell for every statically resolvable free variable, including
   names with no object at callable-definition time.
4. Connect first binding and rebinding to that cell.
5. Store lexical captures in callable summaries and refresh current bindings
   when mutation and return effects are applied.
6. Preserve capture substitution when a factory returns a callable.
7. Avoid merging callable identities with all closure objects.

## Verification

Each attack probe must:

- produce 100 runtime annotations whose value is `typing.Any`;
- pass repository Ruff and strict mypy;
- produce collector count 100;
- trigger scope, total, layer, and file ratchets.

Required variants:

- named function defined before storage binding;
- lambda stored in a registry before storage binding;
- factory returning a function before its enclosing storage binding;
- nested function chain with a later enclosing binding.
- sibling `nonlocal` rebinding and module-level helper `global` rebinding.

Run collector/data-flow tests, matrix tests, full Ruff, active-tree mypy,
compileall, doctor, v14/security/latest/GA/full release checks, full pytest,
Nightly LTS, and independent Reviewer Package verification.

## Release

Commit only after local review and clean checks. Push the final SHA, require
Quality and Nightly success, create an annotated `v14.3.4` tag, publish the
Reviewer Package with SHA-256 and verification JSON, and mark v14.3.3 as
superseded only after v14.3.4 is fully published.
