# v14.2.5 MusicForge Explicit Any Class Global 作用域收集器安全修复施工图

日期：2026-07-22

版本性质：v14.2.4 质量门禁 hotfix

推荐基线：v14.1.2，直到本版完成最终发布验收

## 问题

schema 7 没有处理 `ast.Global` 和 `ast.Nonlocal`。class body 可以通过
`global Alias` 把模块 Alias 改成 `typing.Any`，而 collector 把赋值或
import 错记在临时 class scope，导致后续 100 个真实 Any 注解计数为 0。

## 实施范围

- collector 升级到 schema 8。
- lexical scope 进入前收集 global/nonlocal declarations。
- 模块顶层执行的 class body global assignment/import 写回模块 scope。
- 无法可靠建模的函数运行期、跨控制流和 nonlocal Any alias flow 硬阻断。
- 普通非类型 global 状态不得误报。
- 精确攻击语料进入独立 `v1425.explicit_any_class_global_scope_smoke`。
- 不提高 total、layer、affected-file、per-file、复杂度或 recovery ceiling。
