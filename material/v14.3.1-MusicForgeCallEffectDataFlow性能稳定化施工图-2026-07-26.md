# v14.3.1 MusicForge Call-Effect Data Flow 性能稳定化施工图

## 定位

v14.3.1 是 v14.3.0 的性能稳定化修正版，不增加业务功能，不移动或删除
已经推送的 v14.3.0 tag。

## 问题

schema 14 的安全语义正确，但 `FlowValue` 同时携带 union-find 组件的全部
成员，导致全树采集出现集合放大。五个独立 CI runner 上
`v140.interface_application_boundary_smoke` 均超过原有 180 秒门禁。

## 实施

1. `FlowValue` 只保存 canonical root。
2. 成员、cell、wildcard、escape、taint 继续由 data-flow kernel 管理。
3. checkpoint 等必须检查历史 identity 的路径才展开成员。
4. 新增 1,000 对象组件压缩回归与 v14.3.1 smoke。
5. 不提高 Explicit Any、layer、file、复杂度、覆盖率、recovery 或性能预算。

## 验收

- v14.3 全部攻击与安全控制回归保持通过。
- 全树 Explicit Any 结果和 scope blockers 不变。
- 本地 collector 时间显著低于 v14.3.0。
- Quality 与 Nightly LTS 在最终 SHA 上通过。
- Reviewer Package 独立 `--require-final` 验证通过。
