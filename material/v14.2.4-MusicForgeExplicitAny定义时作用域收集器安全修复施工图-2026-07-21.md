# v14.2.4 MusicForge Explicit Any 定义时作用域收集器安全修复施工图

日期：2026-07-21

推荐基线：v14.1.2，直到本版完成最终发布验收

## 问题

schema 6 隔离了 lambda body，但同时跳过了 lambda defaults。普通函数、
async function 和 class 也没有访问 decorators、defaults、bases、keywords
等定义时表达式。海象赋值因此可以在 Python 外层作用域把 Alias 改成
`typing.Any`，而 collector 仍保留旧 binding。

## 实施范围

- collector 升级到 schema 7。
- lambda defaults 在外层访问，仅 body 被跳过。
- function/async function 按 decorators、defaults、signature、body 处理。
- class 按 decorators、bases/keywords、body 处理。
- 覆盖精确 TYPE_CHECKING 攻击、100 个外层 Any 和求值顺序反例。
- 攻击语料进入独立 `v1424.explicit_any_definition_time_scope_smoke`。
- 不提高 total、layer、affected-file、per-file 或 recovery ceiling。
