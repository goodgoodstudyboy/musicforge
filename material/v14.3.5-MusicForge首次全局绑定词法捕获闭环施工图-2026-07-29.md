# v14.3.5 MusicForge First-Created Module Global Capture Closure

## Objective

Close the schema 16 gap where a callable reads a module global whose first
binding is created later by a sibling helper using `global`. Preserve every
existing quality and performance ceiling.

## Scope

- Upgrade the Explicit Any collector from schema 16 to schema 17.
- Resolve ordinary free names without an enclosing function owner through a
  stable module lexical cell.
- Keep explicit invalid `nonlocal` references fail-closed.
- Cover named functions, lambdas, factories, and nested functions.
- Add `v1435.first_global_lexical_capture_smoke` to every v14 release profile.

## Non-Goals

- Do not add product behavior or broaden the collector beyond Python lexical
  name resolution.
- Do not raise Any, file, layer, complexity, recovery, coverage, or performance
  ceilings.
- Do not add new Ruff, mypy, or release-check suppressions.

## Implementation

1. Search enclosing function owners for an ordinary callable free name.
2. When none exists, use the stable module cell even if the name has no prior
   module assignment.
3. Route sibling helper `global` writes to that same cell.
4. Retain the existing unresolved path for invalid explicit `nonlocal` names.
5. Record the schema 16 to 17 migration and ADR-032 without recalibrating debt
   ceilings.

## Verification

Named-function, lambda, factory, and nested-function probes must each:

- produce 100 runtime annotations whose value is `typing.Any`;
- pass repository Ruff and strict mypy;
- produce collector count 100;
- trigger scope, total, layer, and file blockers.

Run collector and matrix tests, full Ruff, active-tree mypy, compileall,
doctor, v14/security/latest/GA/full release checks, full active and legacy
pytest, Quality CI, Nightly LTS, and independent Reviewer Package validation.

## Release

Commit only after local diff review and clean checks. Push the final SHA,
require Quality and Nightly success, create an annotated `v14.3.5` tag,
publish the Reviewer Package plus checksum and verification JSON, and mark
v14.3.4 superseded only after the replacement release is complete.
